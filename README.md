# LearnMate — Your AI Study Companion

LearnMate turns your lecture PDFs into an AI tutor. Upload a lecture, ask questions, and get answers **from your lecture**, with page citations. It also creates quizzes and tracks your progress.

It runs on an open-source LLM (**Qwen3-4B**) with a **RAG** pipeline built on **LangChain + Chroma**.

## ✨ Features

### 📤 Lecture upload
Upload a PDF lecture (up to 20 MB). The text is extracted, cleaned, split into chunks and stored in a vector database.

<img width="1535" height="733" alt="Screenshot 2026-10-10 190405" src="https://github.com/user-attachments/assets/52c30727-dbea-4ee8-ba5c-916d1abe47a0" />

### 💬 Study Companion (AI chat)
- Answers come from **your lecture**, using RAG.
- Each answer shows its **source pages**.

<img width="1535" height="736" alt="Screenshot 2026-10-10 190415" src="https://github.com/user-attachments/assets/c004ebb0-0ba7-49ec-8062-a26d9d562a94" />

### 📝 AI quizzes
- Multiple-choice questions generated by the LLM from your lecture.
- Choose the number of questions (3–10) and, optionally, a topic.
- After answering, see your score, the correct answers, an explanation and the source page for each question.

<img width="1531" height="732" alt="Screenshot 2026-10-10 190529" src="https://github.com/user-attachments/assets/02319073-660f-47f9-a857-96a8900c4438" />

### 📈 My Progress
- Quizzes completed, average score and best score.
- Score per lecture, weakest first, so you know what to revise.
- Recent quiz history.

<img width="1531" height="741" alt="Screenshot 2026-10-10 190615" src="https://github.com/user-attachments/assets/b474ac08-ec5b-4a41-b97b-21f44d4ef7e0" />

### 🟢 Backend status
Shows whether the AI model is online or offline, with clear error messages when something goes wrong.

## 🏗️ Architecture

```
React frontend  ──►  Vite proxy  ──►  ngrok  ──►  Kaggle notebook (Qwen + LangChain RAG + FastAPI)
```

---

## 📁 Project structure

```
llm/
├── learnmate/            ← React + Vite frontend
│   ├── src/App.jsx       ← all pages: upload, chat, quiz, progress
│   ├── src/App.css       ← styles
│   ├── vite.config.js    ← proxy to the backend
│   └── .env.example      ← backend URL & API key template
└── final-project.ipynb   ← Kaggle notebook: model, RAG pipeline, API
```

**Backend:** FastAPI · Kaggle GPU · ngrok
**Frontend:** React · Vite
